# Customer Churn Prediction

This project focuses on predicting customer churn using machine learning classification models.

## Project Overview

The goal is to identify customers who are likely to churn based on customer and service-related information.

## Workflow

- Data loading and inspection
- Data cleaning and preprocessing
- Target distribution analysis
- Training and testing data splitting
- Feature encoding and scaling
- Handling class imbalance using SMOTE
- Model training and comparison
- Cross-validation
- Model evaluation
- Feature importance analysis

## Models Used

- Random Forest Classifier
- XGBoost Classifier

## Evaluation

The models are evaluated using:

- ROC-AUC Score
- Classification Metrics
- Confusion Matrix
- ROC Curve

The project also includes feature importance analysis to identify the factors that contribute to customer churn.
